# Curso de Gerencia de TIC

Repositorio con materiales, apuntes y recursos del curso de **Gerencia de Tecnologías de la Información y Comunicación (TIC)**.

## 📋 Descripción

Este repositorio recopila el contenido desarrollado a lo largo del curso, incluyendo teoría, casos prácticos, trabajos y proyectos relacionados con la gestión estratégica de las TIC en las organizaciones.

## 🎯 Objetivos del curso

- Comprender el rol estratégico de las TIC dentro de las organizaciones.
- Aplicar marcos y metodologías de gobierno y gestión de TI (COBIT, ITIL, PMI, etc.).
- Desarrollar habilidades de planificación, dirección y control de proyectos tecnológicos.
- Evaluar el impacto de las decisiones tecnológicas en los objetivos del negocio.

## 📂 Contenido del repositorio


## 🛠️ Temas cubiertos

- Gobierno y gestión de TI
- Planeamiento estratégico de TIC
- Gestión de proyectos tecnológicos
- Gestión de riesgos y seguridad de la información
- Frameworks: COBIT, ITIL, PMBOK
- Transformación digital
